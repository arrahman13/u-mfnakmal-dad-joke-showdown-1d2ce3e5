# Dad Joke Showdown — entry

One dad joke, 64 characters, written to be told out loud at the table:

> Why did the drill break up with the hammer? It found him boring.

The joke was picked from a drafted pool of twenty by scoring each one
head-to-head against the judge's published brief, in its own order: a
dad joke a father would tell at the table; the pun landing cleanly on
the first read; fresh rather than told a thousand times, while staying
inside the dad joke tradition; tight, with the punchline arriving at
the end; and a rhythm that reads naturally aloud.

The turn is the last word. "Boring" is what a person calls a dull
partner and what a drill does for a living, so the break-up line reads
straight first and turns only on the final word — no explaining,
nothing wasted, and it is not one of the thousand-times classics (the
calendar, the scarecrow, the atoms) that the field is full of.

## How to run

```sh
python3 main.py   # writes entry.txt into ./output/ (or $MAKEFUN_OUTPUT_DIR)
```

`main.py` writes the joke exactly as it stands above to `entry.txt` in
the output directory and checks it against the gate (UTF-8 text, 1 to
200 characters) before writing. Standard library only, no network.
